Every release, one line of truth.

+

The shell, search, glob and find run in-process, no fork for a single call.

v0.5.xadded

Where the external binaries are missing the agent is blind, and where they exist every call is a fork. Mars links the real implementations, ripgrep, glob, find and a bash with sessions, into one binary alongside thirty-six built-in tools.

+

Every write goes through a real language server, so a rename updates re-exports before the file moves.

v0.9.xadded

A rename calls workspace/willRenameFiles, so barrel files and re-exports follow before the move. TypeScript and Biome servers attach on the same write. Turn it off with --no-lsp on the switches below.

+

A real debugger over DAP (lldb, dlv, debugpy) instead of print statements.

v0.7.xadded

Breakpoints, stepping and inspection run through the Debug Adapter Protocol, so the agent debugs in the same session your editor would. No restart loop, no scattered logging.

+

Subagents run in isolated worktrees and hand back schema-validated results.

v0.6.xadded

Work is fanned out into separate worktrees, each subagent isolated, and the result comes back against a schema rather than free prose. /collab shares a live session; /review returns a ranked verdict.

+

Persistent Python and JS cells run live and can call back into the agent's tools.

v0.9.xadded

An eval cell keeps its state across calls, so a plot or a data pass can be built up turn by turn and then read by the agent that asked for it. read also opens archives, SQLite and PDFs.

−

The external find fork was removed; search is wholly in-process.

v0.5.xremoved

One less binary to find, one less version to disagree with. Removing the external dependency is the kind of entry a register keeps honest: what changed, when, and why.

What the agent may touch

Each flag is passed or cleared; the consequence prints under it.

--prewalkThe first edit hands off to a smaller model.

A one-shot handoff at the first eligible edit or write turn, gated on a successful todo call. --prewalk-into picks a different target than the smol role.

--plan-yoloPlan read-only, then execute unattended.

Starts in read-only plan mode, auto-approves the model's own plan, then switches to the execution target to implement it.

--advisorA second reader watches every turn.

A passive reviewer reads each turn and injects notes; it never takes the turn itself.

--no-lspClears language servers, formatting and diagnostics.

Left clear, LSP tools run on every write and renames go through workspace/willRenameFiles, so re-exports and barrel files follow before the file moves.

--auto-approveForce the yolo approval tier.

Explicit tool and user policies still apply, and so do provider safety checks. This raises the ceiling, it does not remove the checks.
