What a session looks like

zsh — mars

Install

One command. The script downloads the prebuilt binary for your platform and verifies its checksum. On Windows it also adds the install directory to your user PATH.

macOS & Linux

curl -fsSL https://getmars.eu.cc/install | sh

Installs to ~/.local/bin and tells you if that directory is not on your PATH. Override the location with MARS_INSTALL_DIR (legacy PI_INSTALL_DIR is still honored).

Windows (PowerShell)

irm https://getmars.eu.cc/install.ps1 | iex

Installs to %LOCALAPPDATA%\mars and adds it to your user PATH.

Prefer to do it by hand? Grab the archive for your platform from GitHub Releases — mars-<platform>-<arch> for linux-x64, linux-arm64, darwin-x64, darwin-arm64, win32-x64, and win32-arm64.

What you get

Out of the box, with nothing to wire up.

  • 75 providers
  • 36 built-in tools
  • ~290k lines of Rust core
  • 3 platforms
  • MIT licensed

The IDE, wired in

LSP calls sit on every write: ask for a rename and the call goes through workspace/willRenameFiles, so re-exports, barrel files, and aliased imports follow. Debugging is real too — attach lldb, dlv, or debugpy and step.

Native all the way down

ripgrep, glob, and find run in-process instead of shelling out. bash is brush, with sessions that survive across calls and the common coreutils ported into the Rust builtins crate. The same binary runs on macOS, Linux, and Windows — no WSL bridge.

Any model, tuned per model

Pick from 75 providers in the bundled catalog. Prompts are adjusted for each one, completions generate themselves from the live command metadata, and --resume resolves against your on-disk sessions.

Subagents, review, and shareable sessions

task fans work into isolated worktrees and returns schema-validated results. /review ranks issues P0–P3 with a verdict. /collab puts your live session on a relay and hands back a link — frames are sealed client-side.
