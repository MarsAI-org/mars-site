The Command Suite

Every write passes through language server verification and AST validation before disk commit.

  • LSP Rename & Diagnostics LSP

    Routes edits through real language servers. Hits workspace/willRenameFiles so re-exports and imports update before files move.

  • Code Review Subagent /review

    Adversarially validates findings, categorizes severity from P0 to P3, and produces structured verification ledgers.

  • Isolated Worktree Tasks task

    Spawns child agents in isolated Git worktrees. Runs tests independently and merges schema-validated outcomes.

  • Native DAP Debuggers debug

    Attaches real debuggers via DAP (lldb, dlv, debugpy) to set breakpoints, inspect runtime memory, and trace core dumps.

  • Universal Scheme Reader read

    Reads local filesystem files, archives, SQLite databases, PDF tables, URLs, and internal schemes like pr:// or issue://.

  • Persistent Python Cells eval

    Evaluates persistent code cells with direct access to agent tools, inline charts, and statistical computation.

How Mars Operates

Nothing on the critical execution path forks external shell processes. Search, walk, and shell are compiled in-process.

In-Process Engine

ripgrep, glob, find, and bash run as Rust crates linked inside the single binary. 46 coreutils execute as builtins with zero subshell overhead.

LSP on Every Write

Every modification syncs with TypeScript, Rust-Analyzer, Pyright, or Biome servers, keeping types and dependencies intact across renames.

Worktree Isolation

Subagents run concurrent verification loops in clean Git worktrees, isolating uncommitted work from your active editor tree.

DAP Runtime Debug

Connects directly to language debug adapters to step through active frames, evaluate local variables, and diagnose segfaults live.
