+

Shell, ripgrep, glob and find execute in-process — zero subprocess fork per tool call.

corebuilt-in

Where external binaries are missing, typical agents fail; where they exist, every call forks a process. Mars compiles ripgrep, glob, find, coreutils and session-aware bash directly into one binary across macOS, Linux and Windows.

+

Every write runs through a real language server, updating re-exports before files move.

idebuilt-in

Renames trigger workspace/willRenameFiles so imports and barrel files update cleanly before the move. Multiple language servers (such as TypeScript and Biome) attach on the same write, with ACP support for Zed.

+

Real DAP debugger support (lldb, dlv, debugpy) instead of guesswork logging.

idebuilt-in

Set breakpoints, step frames, and inspect runtime state through the Debug Adapter Protocol — debugging inside the same protocol your IDE speaks without scattering temporary print statements.

+

Subagents run in isolated worktrees and return schema-validated results, plus /review and /collab.

agentsbuilt-in

Parallel workers operate on independent worktrees and hand back structured, schema-checked outputs instead of loose prose. /review scores P0–P3 findings with a verdict; /collab shares live sessions.

+

Persistent Python & JS cells, unified read across archives/SQLite/PDFs, and cross-session memory.

runtimebuilt-in

Stateful eval cells call back into agent tools across turns. The unified read tool opens local paths, archives, SQLite databases, PDFs, URLs, and internal schemes (pr://, issue://, agent://, skill://, conflict://) alongside curated cross-session memory.

−

External WSL bridge & find/ripgrep forks eliminated — identical native behavior on every OS.

coreeliminated

No version drift across host utilities and no Linux VM indirection on Windows. One prebuilt binary delivers consistent search, shell, and file primitives everywhere.

What the agent may touch

Toggle any flag to inspect its exact behavior and compose the resulting CLI invocation live.

$mars

--prewalkHand off the first eligible edit turn to a smaller model.

A one-shot handoff at the first eligible edit or write turn, gated on a successful todo call. Use --prewalk-into to choose a target other than the smol role.

--plan-yoloPlan read-only, then execute unattended.

Starts in read-only plan mode, auto-approves the model's own plan, then switches to the execution target to implement it end to end.

--advisorA second passive reader reviews every turn.

A passive reviewer inspects each turn and injects targeted notes without taking over execution.

--no-lspDisable language servers, formatting and diagnostics.

Left clear, LSP tools run on every write and renames go through workspace/willRenameFiles so re-exports stay intact before files move.

--auto-approveRaise the approval ceiling to the yolo tier.

Explicit tool policies, user rules, and provider safety checks still apply — this raises the approval ceiling without removing guardrails.
